# Detailed Technology Tooltips v1.2.11

- Clear, concise purpose descriptions for visible blueprint unlocks, with related upgrades highlighting what changes.
- Native material icons with names and quantities, readable spacing, and tooltip width adapted to the current language's materials.
- Selective emphasis and native symbols for church/graveyard quality and alchemy categories.
- Consistent mouse/gamepad presentation and support for all 11 game languages.
- Preserves useful native item descriptions and exact recipe stations; prayer unlocks remain owned by vanilla or PrayerClarity.
- Responsive Technology branch switching. Fixed appearance, with no F2 settings window.
- No changes to progression, crafting, construction mechanics, hidden unlocks or saves.

Requires Graveyard Keeper 1.407 on Windows PC with BepInEx 5. Replace the existing DetailedTechnologyTooltips.dll in BepInEx/plugins; keep one active copy.

The downloadable DLL is the exact runtime-tested build. Original source is available under MPL-2.0 at the release tag.
