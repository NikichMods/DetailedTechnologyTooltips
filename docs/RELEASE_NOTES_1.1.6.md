# Detailed Technology Tooltips v1.1.6

- Blueprint Technology tooltips now list every native build menu in Graveyard Keeper 1.407 that can build the same construction variant.
- Multi-location blueprints such as Vine press, Quarry/Yard structures, and Trunk no longer depend on current save progression to decide which location names are shown.
- Ordinary recipe station information, requirements, localization, progression, saves, and hidden Technology unlock presentation remain unchanged.
- Includes the previously accepted 1.0.2 tooltip, localization, Work/Perk, Better Save Soul Remote Control, Pyrite, CJK wrapping, quantity-token repair, and viewport behavior.

Requires Graveyard Keeper 1.407 on Windows PC with BepInEx 5.
