# Detailed Technology Tooltips 1.0.2

First stable release candidate.

Detailed Technology Tooltips adds practical detail directly to visible Technology-tree unlock tooltips in Graveyard Keeper:

- recipe unlocks show what they require and the exact station(s) where that unlocked recipe is crafted;
- blueprint/build unlocks show build requirements and the owning build menu;
- specifically verified sparse Work/Perk unlocks receive concise source/effect explanations;
- Better Save Soul Remote Control explains that remote workstation control is accessed from the map and requires a Soul Receiver in the target area for remote actions;
- Pyrite is identified as not implemented in the current game version;
- native item, station and build-desk names remain driven by the active game localization;
- hidden Technology unlocks remain hidden.

Version 1.0.2 also includes the locale-specific list-spacing, CJK line-breaking and quantity-token wrapping fixes found during release-candidate testing.

The mod is informational only. It does not change technology progression, recipes, build mechanics, saves, story/DLC gating or unrelated tooltips.

### Languages

English, German, French, Brazilian Portuguese, Spanish, Russian, Italian, Polish, Japanese, Simplified Chinese and Korean.

### Compatibility

Tested on Graveyard Keeper 1.407 (Steam, Windows) with all DLC installed.

Other game versions, storefront builds, operating systems and DLC configurations are currently untested rather than known incompatible.

### Installation

Install BepInEx 5, then place `DetailedTechnologyTooltips.dll` in `Graveyard Keeper\BepInEx\plugins`.

When updating, replace the existing DLL instead of keeping multiple versioned copies.
